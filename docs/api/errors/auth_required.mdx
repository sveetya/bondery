## When this happens

No session and no valid API key on a protected route.

## What your integration should do

Send a Better Auth session cookie/token, or use an API key only on integration routes.

## What end users should see

Prompt sign-in (`common.errors.api.auth_required`).

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `authentication_error` |
| **HTTP status** | 401 |
| **code** | `auth_required` |
| **doc_url** | `/docs/api/errors/auth_required` |

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation).
