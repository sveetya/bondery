## When this happens

A domain rule blocked the operation after validation. Affects **Contacts** operations.

## What your integration should do

Verify contact ids, required body fields, and that the record belongs to the authenticated user.

## What end users should see

Translate with `common.errors.api.contact_delete_self_forbidden` when a string exists; otherwise map by domain prefix. Never surface the raw API `message`.

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `authorization_error` |
| **HTTP status** | 403 |
| **code** | `contact_delete_self_forbidden` |
| **doc_url** | `/docs/api/errors/contact_delete_self_forbidden` |

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation).
