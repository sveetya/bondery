## When this happens

A non-admin session hit an admin-only route (`verifyAdmin`).

## What your integration should do

Use a session for an account with `user.role = admin` (Better Auth platform admin). API keys cannot call admin routes.

## What end users should see

Show an access denied message — this is operator-only.

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `authorization_error` |
| **HTTP status** | 403 |
| **code** | `admin_required` |
| **doc_url** | `/docs/api/errors/admin_required` |

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation).
